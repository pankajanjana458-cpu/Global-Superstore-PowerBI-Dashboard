# 📊 Global Superstore Executive Dashboard

An interactive **Power BI Executive Dashboard** created using the Global Superstore dataset to provide a clear overview of sales, profit, customers, products, regions, and customer segments.

## 🎯 Project Overview

This project presents an executive-level Power BI dashboard designed to explore overall business performance through interactive visualizations and key performance indicators.

The dashboard brings important business metrics together in a single view and allows users to analyze performance across different dimensions.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## 📌 Dashboard Highlights

### Key Performance Indicators

The dashboard includes:

- 💰 Total Sales
- 📈 Total Profit
- 🛒 Total Orders
- 👥 Total Customers
- 📊 Profit Margin
- 📦 Total Quantity
- 💵 Average Order Value

### Visual Analysis

The dashboard provides visual analysis of:

- Sales Trend
- Sales by Region
- Sales by Segment
- Sales by Category
- Top 5 Products by Sales
- Top Customers by Sales
- Monthly Profit Trend
- Sales vs Profit

## 🎛️ Interactive Filters

The dashboard includes interactive filters for:

- Year
- Month
- Region
- Ship Mode
- Category

These filters allow users to explore the dashboard based on different business dimensions.

## 📊 Dashboard Purpose

The main objective of this dashboard is to provide an interactive and easy-to-understand overview of business performance.

It combines key metrics and visualizations into a single executive view for exploring sales and profitability trends, regional performance, customer segments, categories, products, and customers.
